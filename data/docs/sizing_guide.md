# Sizing guide

*Fictional policy for demo. Ferro Cycles is not a real company.*

| Size | Rider height |
|------|--------------|
| S    | 155 to 167 cm |
| M    | 167 to 178 cm |
| L    | 178 to 189 cm |
| XL   | 189 to 200 cm |

If you are between two sizes: choose the smaller size for a more agile ride and the larger size
for more stability. Metro C is only available in S, M and L.
